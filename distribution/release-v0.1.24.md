# ScreenTake 0.1.24 (build 26)

**[Download the signed and notarized DMG](https://github.com/sso-ss/ScreenTake/releases/download/v0.1.24/ScreenTake-0.1.24-build26.dmg)** · [SHA-256 checksum](https://github.com/sso-ss/ScreenTake/releases/download/v0.1.24/ScreenTake-0.1.24-build26.dmg.sha256)

For Apple Silicon Macs (M1 or newer) running macOS 13 or later.

- Check for updates once at app launch, even when periodic checks are disabled. Checks wait until permission setup, recording, or media processing has finished.
- Keep optional update checks every 24 hours while ScreenTake is running.
- Show a persistent red dot on the menu bar icon, Settings button, and Updates sidebar item when an update is available. Opening Settings does not dismiss the reminder.
- See the available version in Settings → Updates and open the installer from there.

Save your project before updating. ScreenTake 0.1.16 and later can install this release with **ScreenTake → Check for Updates…**. For a manual installation, quit ScreenTake, open the DMG, drag **ScreenTake.app** into **Applications**, and reopen it.
