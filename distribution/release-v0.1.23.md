# ScreenTake 0.1.23 (build 25)

**[Download the signed and notarized DMG](https://github.com/sso-ss/ScreenTake/releases/download/v0.1.23/ScreenTake-0.1.23-build25.dmg)** · [SHA-256 checksum](https://github.com/sso-ss/ScreenTake/releases/download/v0.1.23/ScreenTake-0.1.23-build25.dmg.sha256)

For Apple Silicon Macs (M1 or newer) running macOS 13 or later.

- Open an in-app bug report from error alerts or **ScreenTake → Report a Bug…**. Recent ScreenTake logs and app/macOS versions are prepared automatically; review, edit, or exclude logs before continuing.
- Capture the ScreenTake window or attach an image. Drag over sensitive areas to cover them with solid black, then save a flattened screenshot without source photo metadata.
- Continue to a public GitHub issue with the report filled in. A GitHub account is required; paste the reviewed screenshot with Command-V before submitting. Videos and project files are not included.

Save your project before updating. ScreenTake 0.1.16 and later can install this release with **ScreenTake → Check for Updates…**. For a manual installation, quit ScreenTake, open the DMG, drag **ScreenTake.app** into **Applications**, and reopen it.
