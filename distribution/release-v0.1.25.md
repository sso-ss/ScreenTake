# ScreenTake 0.1.25 (build 27)

**[Download the signed and notarized DMG](https://github.com/sso-ss/ScreenTake/releases/download/v0.1.25/ScreenTake-0.1.25-build27.dmg)** · [SHA-256 checksum](https://github.com/sso-ss/ScreenTake/releases/download/v0.1.25/ScreenTake-0.1.25-build27.dmg.sha256)

For Apple Silicon Macs (M1 or newer) running macOS 13 or later.

- Enable **Smooth Motion** in cursor settings before recording or while editing.
- Adjust cursor smoothing from 20 to 250 ms to reduce small, rapid movements.
- Keep smoothing settings in saved projects, with matching editor previews and exported videos.
- Continue opening older projects with smoothing off by default; invalid smoothing values are rejected safely.

Save your project before updating. ScreenTake 0.1.16 and later can install this release with **ScreenTake → Check for Updates…**. For a manual installation, quit ScreenTake, open the DMG, drag **ScreenTake.app** into **Applications**, and reopen it.
