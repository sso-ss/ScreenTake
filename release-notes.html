ScreenTake 0.1.11

Update reminders now follow the current ScreenTake releases.

What’s new

  • The app checks the current ScreenTake release page for updates when open and ready to use, about once a day.
  • The feedback shortcut opens the current ScreenTake issue page.
  • Version 0.1.10 users can discover this update through the previous release page.
Download 0.1.11 for Apple Silicon

Install

Requires an Apple Silicon Mac and macOS 13 or later. Save your work and quit ScreenTake. Open the DMG, drag ScreenTake into Applications, then reopen it. Future update reminders open a download page; installation remains manual.

Test build

This build is signed and notarized by Apple. Make a short test recording and check your export before sharing. Smart zoom and recording reliability are still being refined.

Cursor and zoom re-editing rely on capture data retained in the current app session. Imported or reopened finished videos do not restore that data.
